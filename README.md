# LAB 08 — Flocking y comportamiento colectivo

Proyecto Unity 6 para la práctica CONT3 2026B. Requiere Unity **6000.3.17f1**.

## Abrir y ejecutar

1. Agrega esta carpeta en Unity Hub y espera la importación.
2. Abre `Assets/Lab08/Scenes/00_Menu.unity` y pulsa **Play**.
3. Elige el cardumen o el ejemplo del jefe con soldados.

Los controles están descritos en [LEEME.txt](LEEME.txt). El informe completo está en [Informe_LAB08_Flocking.pdf](Informe_LAB08_Flocking.pdf); las capturas de escenas de Unity están en `Capturas/`.

## Escenas

- `00_Menu`: menú para ambos ejemplos.
- `01_Flocking`: 100 peces, Terrain con colinas, roca central gigante y evitación de obstáculos.
- `02_Soldados`: jefe controlable, marcha animada, seguidores en filas y media luna al detenerse.
